# Python Learning Website (Python)

A simple Python web server that serves a website interface explaining how Python helps people learn programming.

## Prerequisites

- [Python 3](https://www.python.org/downloads/) installed

No extra packages are required (uses Python's built-in `http.server` module).

## Run

1. Open a terminal in this project folder:
   `C:\Users\Irash\Documents\Default Project`

2. Start the server:

   ```bash
   python app.py
   ```

   (On some systems you may need `py app.py` or `python3 app.py`.)

3. Open your browser at:

   [http://127.0.0.1:8000](http://127.0.0.1:8000)

4. Stop the server with `Ctrl + C` in the terminal.

## Files

- `app.py` - Python web server and embedded HTML/CSS page
- `README_python.md` - these instructions
